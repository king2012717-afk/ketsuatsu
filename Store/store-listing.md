## 説明（4000 文字以内）

```
血圧計の表示を撮るだけ。上・下・脈拍を自動で読み取って記録します。

家庭での血圧測定は、続けることが何より大切です。「うちの血圧記録」は、数字を手で打ち込む手間をなくして、記録を続けやすくするためのアプリです。

■ 写真で撮るだけ
血圧計の画面をカメラで撮るか、撮りためた写真から選ぶだけ。収縮期（上）・拡張期（下）・脈拍を自動で読み取ります。SYS / DIA / PULSE のラベルがある機種にも、数字だけが並ぶ機種にも対応しています。読み取った結果は必ず確認画面に出るので、違っていればその場で直せます。

■ まとめて記録
写真は何枚でも一度に選べます。写真の撮影日時をそのまま測定日時に使うので、あとからまとめて入力しても「実際に測った時刻」で残ります。

■ 続けやすいリマインダー
1 日に何回でも設定できます。朝・昼・晩それぞれの時刻を決められるほか、曜日ごとに時刻を変えることもできます（平日は朝だけ、休日は朝晩、など）。

■ 見返しやすいグラフ
期間は 1 週間・1 か月・3 か月・半年・1 年・全期間・期間指定から選べます。表示は 平均・朝・昼・晩・すべて を切り替えられるので、朝だけの傾向、晩だけの傾向も追えます。期間が長いときは自動で週ごと・月ごとの平均に切り替わり、点がつぶれません。

■ 判定は日本のガイドラインに準拠
日本高血圧学会「高血圧治療ガイドライン 2019」の分類にもとづき、正常血圧から III 度高血圧までを色分けして表示します。家庭血圧と診察室血圧では基準が 5mmHg 違うため、設定で切り替えられます。

■ 朝と晩の平均
家庭血圧は朝と晩それぞれの平均で判断します。時間帯ごとの平均と、朝晩の差（モーニングサージの目安）を表示します。

■ ヘルスケア連携・CSV 書き出し
記録は Apple の「ヘルスケア」と双方向でやり取りできます。CSV でも書き出せるので、受診のときに印刷して持参することもできます。

■ データは端末の中に
記録はお使いの iPhone の中だけに保存されます。アカウント登録は不要で、記録した血圧などのデータを外部のサーバーへ送信することはありません。

■ こんな方に
・毎日血圧を測っているが、記録するのが面倒で続かない
・血圧手帳への転記に時間がかかっている
・受診のときに、まとめた記録を医師に見せたい
・家族の血圧も気にかけている

ご注意
本アプリは医療機器ではありません。記録と傾向の把握を助けるためのものであり、診断・治療の判断は医師にご相談ください。写真からの読み取り結果は、保存する前に必ずご確認ください。
本アプリは無料でご利用いただけます。画面の上部に広告を表示します。
```

## App のプライバシー（データ収集）

> **広告（Unity LevelPlay）とアクセス解析（Firebase Analytics）を入れているため、「データを収集していません」は選べません。** 選ぶとリジェクトや後日の是正要求の対象になります。以下のとおり申告してください。

血圧の記録そのものは端末内にのみ保存され、外部へ送信されません。申告が必要なのは、次の SDK が扱うデータです。

- **Unity LevelPlay**（Unity Ads アダプタを含む）… 広告の配信・測定
- **Firebase Analytics**（`FirebaseAnalyticsCore`、IDFA なし）… 操作イベントの集計。送るイベントとパラメータは `FIREBASE_ANALYTICS.md` のとおりで、健康情報・個人情報は含まない

次の項目を「収集する」にして、それぞれ下表の目的にチェックを入れます。目的の名前は App Store Connect の画面上の表記に合わせています（「分析」は画面上では **アナリティクス**）。

| データの種類 | チェックする目的 | 主な SDK | ユーザの識別情報に関連付け | トラッキングに使用 |
| --- | --- | --- | --- | --- |
| 識別子 → **デバイス ID** | サードパーティ広告 / アナリティクス | LevelPlay / Firebase | いいえ | **はい** |
| 使用状況データ → **広告データ** | サードパーティ広告 | LevelPlay | いいえ | **はい** |
| 使用状況データ → **製品の操作** | サードパーティ広告 / アナリティクス | LevelPlay / Firebase | いいえ | **はい** |
| 位置情報 → **おおよその位置情報** | アナリティクス | Firebase（IP アドレスから国・地域を推定） | いいえ | いいえ |

データの種類と目的は `Ketsuatsu/PrivacyInfo.xcprivacy` と同じです（仕様書 2-13）。どちらかを変えたら、もう片方も合わせてください。

> **「トラッキングに使用」だけは、App Store Connect とマニフェストで意図的に違えています。**
> - App Store Connect：ATT を出すアプリは「はい」が必須（1.3 (1) で提出を止められた）
> - `PrivacyInfo.xcprivacy`：アプリ自身はトラッキングしないので `NSPrivacyTracking` は `false`、トラッキング先ドメインのキーは書かない。`true` にするとドメインを書く必要があり、空のままだと ITMS-91064 で弾かれる（1.3 (2) で発生）。広告 SDK のマニフェストもトラッキング先ドメインを宣言していない

> **1.3 で変わる点（1.2 からの変更）**
> - 「おおよその位置情報（アナリティクス）」を追加（Firebase Analytics）
> - 「診断（クラッシュデータ・パフォーマンスデータ・その他の診断データ）」を外す。AdMob を使っていたころの申告で、現在の SDK は収集を宣言していない（LevelPlay 9.6.0 の SDK マニフェストは収集データなし。Firebase Analytics はクラッシュデータを扱わない）

> 提出前に Google の案内「Firebase の App Store データ開示」（https://firebase.google.com/docs/ios/app-store-data-collection ）で、Analytics の申告項目が上の表と合っているか確認してください（こちらの環境からはページを開けず、未確認です）。

目的の選択肢のうち、次の 3 つはチェックしません。

- **デベロッパの広告またはマーケティング** … 自社広告の配信やユーザーへの宣伝送信は行っていない
- **製品のパーソナライズ** … 表示内容をユーザーごとに変える仕組みはない
- **その他の目的** … 該当なし

- **健康とフィットネス（血圧など）は申告不要**です。端末内とヘルスケアの中だけで完結し、開発者も第三者も受け取りません。アクセス解析にも、血圧値・脈拍・服薬・メモ・写真・ヘルスケアのデータは送っていません。
- 本アプリは 1.3 から、初回起動時に広告の同意画面と **ATT（トラッキングの許可を求める iOS の確認画面）** を表示します（仕様書 1-5）。`PrivacyInfo.xcprivacy` の `NSPrivacyTracking` は `false` です（上の注記を参照）。
- **ATT を出すアプリは、少なくとも 1 つのデータを「トラッキングに使用：はい」と申告しないと提出できません**（1.3 の提出時に App Store Connect で止められた）。ATT で許可された場合、広告 SDK がこれらを他社のデータと組み合わせて広告に使うため、広告に使う 3 項目（デバイス ID・広告データ・製品の操作）を「はい」にします。
- おおよその位置情報は計測（Firebase）だけに使い、Firebase は IDFA を扱わない `FirebaseAnalyticsCore` なので「いいえ」のままです。
- 最新の申告内容は、Unity の LevelPlay のドキュメント（App Store のプライバシーに関する案内）と、上記の Firebase の案内でも確認してください。

## 規制対象の医療用デバイスに関する申告

**「いいえ」** を選びます。

根拠:

- 本アプリは血圧を**測定しない**。測定はユーザーが別途所有する血圧計（それ自体が規制対象の医療機器）が行い、本アプリはその結果を記録・表示するだけ
- 判定区分の表示は、日本高血圧学会が公表している分類をそのまま参考情報として示すものであり、診断や治療方針の指示は行わない
- 日本の薬機法でも、測定値を記録・表示・転送するだけのプログラムは原則としてプログラム医療機器（SaMD）の対象外とされている
- アプリ内と App Store の説明文の両方に、医療機器ではない旨と医師への相談を促す記載をしている

将来、次のような機能を追加する場合は再検討が必要:

- 端末のセンサーなどで血圧そのものを測定する
- 記録から病名を推定する、受診の要否を判定するなど診断に踏み込む
- 服薬量の調整を提案するなど治療の指示を行う

### 備考（Notes）

```
このアプリは、家庭用血圧計で測定した値を記録・可視化するためのものです。

【HealthKit の用途】
・書き出し: ユーザーがアプリ内で記録した血圧（収縮期・拡張期）と脈拍を、ユーザーが許可した場合のみヘルスケアへ保存します。
・読み取り: ヘルスケアに保存済みの血圧・脈拍を、ユーザーの操作（設定 →「ヘルスケアから取り込む」）でアプリへ取り込みます。
・HealthKit から取得したデータを広告・マーケティング・第三者提供に使用することはありません。データは端末外へ送信されません。

【カメラ・写真の用途】
血圧計の液晶に表示された数値を Vision フレームワークの文字認識で読み取るためだけに使用します。撮影した画像は端末内にのみ保存され、送信されません。

【広告と ATT】
広告は Unity LevelPlay（ironSource Ads／Unity Ads）です。バナーはすべての画面の上部に表示します。
初回起動時に同意画面のあと、選択に関わらず iOS のトラッキング確認を表示します。同意画面で選んだ内容は、設定 →「広告」で変更できます。
記録した血圧などの健康情報は広告に使用しません。

【動作確認の手順】
1. ホーム →「写真から記録」→「写真から選ぶ」で、血圧計の写真を選ぶと数値が自動入力されます。
   ※シミュレータではカメラを使用できないため、写真ライブラリからの読み取りでご確認ください。
   ※確認用の血圧計の写真は、審査用の添付ファイルに含めています。
2. 「手入力」からは通常のフォームで記録できます。
3. 設定 → リマインダーで通知時刻を設定できます。
4. 設定 → ヘルスケア連携から、書き出しと取り込みを確認できます。

【医療機器に関する補足】
本アプリは測定機能を持たず、ユーザーが別途所有する血圧計の測定結果を記録するものです。診断・治療の助言は行いません。アプリ内（設定 →「このアプリについて」）と App Store の説明文の両方に、医療機器ではない旨と医師への相談を促す記載をしています。
```

> **審査用の添付ファイル**: 血圧計の表示が写った写真を 1 枚、App Review Information の「添付ファイル」に付けてください。審査担当者が読み取り機能を試せるようにするためです。
