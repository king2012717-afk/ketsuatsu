## 説明（4000 文字以内）

```
血圧計の表示を撮るだけ。上・下・脈拍を自動で読み取って記録します。

家庭での血圧測定は、続けることが何より大切です。「うちの血圧記録」は、数字を手で打ち込む手間をなくして、記録を続けやすくするためのアプリです。

■ 写真で撮るだけ
血圧計の画面をカメラで撮るか、撮りためた写真から選ぶだけ。収縮期（上）・拡張期（下）・脈拍を自動で読み取ります。SYS / DIA / PULSE のラベルがある機種にも、数字だけが並ぶ機種にも対応しています。読み取った結果は必ず確認画面に出るので、違っていればその場で直せます。

■ まとめて記録
写真は何枚でも一度に選べます。写真の撮影日時をそのまま測定日時に使うので、あとからまとめて入力しても「実際に測った時刻」で残ります。

■ 続けやすいリマインダー
1 日に何回でも設定できます。朝・昼・晩それぞれの時刻を決められるほか、曜日ごとに時刻を変えることもできます（平日は朝だけ、休日は朝晩、など）。

■ 見返しやすいグラフ
期間は 1 週間・1 か月・3 か月・半年・1 年・全期間・期間指定から選べます。表示は 平均・朝・昼・晩・すべて を切り替えられるので、朝だけの傾向、晩だけの傾向も追えます。期間が長いときは自動で週ごと・月ごとの平均に切り替わり、点がつぶれません。

■ 判定は日本のガイドラインに準拠
日本高血圧学会「高血圧治療ガイドライン 2019」の分類にもとづき、正常血圧から III 度高血圧までを色分けして表示します。家庭血圧と診察室血圧では基準が 5mmHg 違うため、設定で切り替えられます。

■ 朝と晩の平均
家庭血圧は朝と晩それぞれの平均で判断します。時間帯ごとの平均と、朝晩の差（モーニングサージの目安）を表示します。

■ ヘルスケア連携・CSV 書き出し
記録は Apple の「ヘルスケア」と双方向でやり取りできます。CSV でも書き出せるので、受診のときに印刷して持参することもできます。

■ データは端末の中に
記録はお使いの iPhone の中だけに保存されます。アカウント登録は不要で、外部のサーバーへ送信することはありません。

■ こんな方に
・毎日血圧を測っているが、記録するのが面倒で続かない
・血圧手帳への転記に時間がかかっている
・受診のときに、まとめた記録を医師に見せたい
・家族の血圧も気にかけている

ご注意
本アプリは医療機器ではありません。記録と傾向の把握を助けるためのものであり、診断・治療の判断は医師にご相談ください。写真からの読み取り結果は、保存する前に必ずご確認ください。
本アプリは無料でご利用いただけます。画面の上部に広告を表示します。
```

## App のプライバシー（データ収集）

> **広告（LevelPlay）を入れているため、「データを収集していません」は選べません。** 選ぶとリジェクトや後日の是正要求の対象になります。以下のとおり申告してください。

血圧の記録そのものは端末内にのみ保存され、外部へ送信されません。申告が必要なのは、Google Mobile Ads SDK が広告配信のために扱うデータです。

次の 4 つを「収集する」にして、それぞれ下表の目的にチェックを入れます。目的の名前は App Store Connect の画面上の表記に合わせています（「分析」は画面上では **アナリティクス**）。

| データの種類 | チェックする目的 | ユーザの識別情報に関連付け | トラッキングに使用 |
| --- | --- | --- | --- |
| 識別子 → **デバイス ID** | サードパーティ広告 / アナリティクス | いいえ | いいえ |
| 使用状況データ → **広告データ** | サードパーティ広告 | いいえ | いいえ |
| 使用状況データ → **製品の操作** | サードパーティ広告 / アナリティクス | いいえ | いいえ |
| 診断 → **クラッシュデータ**、**パフォーマンスデータ**、**その他の診断データ** | アプリの機能 | いいえ | いいえ |

目的の選択肢のうち、次の 3 つはチェックしません。

- **デベロッパの広告またはマーケティング** … 自社広告の配信やユーザーへの宣伝送信は行っていない
- **製品のパーソナライズ** … 表示内容をユーザーごとに変える仕組みはない
- **その他の目的** … 該当なし

- **健康とフィットネス（血圧など）は申告不要**です。端末内とヘルスケアの中だけで完結し、開発者も第三者も受け取りません。
- 上の表は **ATT（トラッキングの許可を求めるダイアログ）を表示しない**前提です。本アプリは IDFA を要求していないため、「トラッキング」はすべて「いいえ」になります。
- 将来 ATT を導入して個人に最適化された広告を配信する場合は、トラッキングを「はい」に変更し、`NSUserTrackingUsageDescription` を `Info.plist` に追加する必要があります。
- 最新の申告内容は Google の案内（「LevelPlay と App Store のプライバシーに関する質問」）でも確認してください。

## 規制対象の医療用デバイスに関する申告

**「いいえ」** を選びます。

根拠:

- 本アプリは血圧を**測定しない**。測定はユーザーが別途所有する血圧計（それ自体が規制対象の医療機器）が行い、本アプリはその結果を記録・表示するだけ
- 判定区分の表示は、日本高血圧学会が公表している分類をそのまま参考情報として示すものであり、診断や治療方針の指示は行わない
- 日本の薬機法でも、測定値を記録・表示・転送するだけのプログラムは原則としてプログラム医療機器（SaMD）の対象外とされている
- アプリ内と App Store の説明文の両方に、医療機器ではない旨と医師への相談を促す記載をしている

将来、次のような機能を追加する場合は再検討が必要:

- 端末のセンサーなどで血圧そのものを測定する
- 記録から病名を推定する、受診の要否を判定するなど診断に踏み込む
- 服薬量の調整を提案するなど治療の指示を行う

### 備考（Notes）

```
このアプリは、家庭用血圧計で測定した値を記録・可視化するためのものです。

【HealthKit の用途】
・書き出し: ユーザーがアプリ内で記録した血圧（収縮期・拡張期）と脈拍を、ユーザーが許可した場合のみヘルスケアへ保存します。
・読み取り: ヘルスケアに保存済みの血圧・脈拍を、ユーザーの操作（設定 →「ヘルスケアから取り込む」）でアプリへ取り込みます。
・HealthKit から取得したデータを広告・マーケティング・第三者提供に使用することはありません。データは端末外へ送信されません。

【カメラ・写真の用途】
血圧計の液晶に表示された数値を Vision フレームワークの文字認識で読み取るためだけに使用します。撮影した画像は端末内にのみ保存され、送信されません。

【動作確認の手順】
1. ホーム →「写真から記録」→「写真から選ぶ」で、血圧計の写真を選ぶと数値が自動入力されます。
   ※シミュレータではカメラを使用できないため、写真ライブラリからの読み取りでご確認ください。
   ※確認用の血圧計の写真は、審査用の添付ファイルに含めています。
2. 「手入力」からは通常のフォームで記録できます。
3. 設定 → リマインダーで通知時刻を設定できます。
4. 設定 → ヘルスケア連携から、書き出しと取り込みを確認できます。

【医療機器に関する補足】
本アプリは測定機能を持たず、ユーザーが別途所有する血圧計の測定結果を記録するものです。診断・治療の助言は行いません。アプリ内（設定 →「このアプリについて」）と App Store の説明文の両方に、医療機器ではない旨と医師への相談を促す記載をしています。
```

> **審査用の添付ファイル**: 血圧計の表示が写った写真を 1 枚、App Review Information の「添付ファイル」に付けてください。審査担当者が読み取り機能を試せるようにするためです。
